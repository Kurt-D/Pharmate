# PharMate Brand Palette

Use blue as the product identity and reserve green, amber, and red for meaningful clinical states.

| Token | Hex | Use |
| --- | --- | --- |
| `--pm-blue-700` | `#0F58C9` | Primary buttons, links, accessible text accent |
| `--pm-blue-600` | `#146EF5` | Brand surfaces, active navigation, illustrations |
| `--pm-blue-400` | `#5AA1FF` | Decorative highlights only |
| `--pm-blue-100` | `#EAF3FF` | Selected and information surfaces |
| `--pm-blue-50` | `#F5F9FF` | Quiet blue backgrounds |
| `--pm-ink` | `#172B49` | Headings and high-emphasis content |
| `--pm-text` | `#31445F` | Body copy |
| `--pm-muted` | `#66758A` | Supporting text |
| `--pm-line` | `#DCE6F2` | Dividers and card borders |
| `--pm-canvas` | `#F5F8FC` | Application background |
| `--pm-success` | `#1F9D55` | Completed or verified states |
| `--pm-warning` | `#B86D00` | Needs review or unresolved states |
| `--pm-danger` | `#D83D4B` | Critical or rejected states |

Do not use semantic colours as decoration. A patient should immediately understand that green means completed, amber means needs attention, and red means urgent or rejected.
